Localization & Clearance

A geometric search-and-clearance framework for rapidly locating multiple interference sources under directional/no-signal observations, uncertainty and limited motion time.

01 / PROBLEM

Turn weak observations into a shrinking feasible region.

The task is not a standard point-estimation problem. The searcher repeatedly receives directional, positive/negative and range-dependent information while moving, so the central object is a set of source locations that remain physically consistent with all observations.

02 / METHOD

Geometry first, optimization second.

A

Half-plane certificates

Directional observations are converted into geometric constraints and maintained as a feasible region rather than a single fragile estimate.

B

Event-triggered modes

Search behavior switches when observations change: directed pursuit, no-signal exploration and local refinement are treated as distinct modes.

C

Coverage certificate

Global coverage logic prevents unresolved regions from being silently ignored when multiple sources or blind sectors are possible.

D

Rolling-horizon selection

Candidate moves are evaluated by information gain, expected localization shrinkage and travel cost instead of fixed spiral motion alone.

03 / EVIDENCE

Trajectory-level validation.

04 / STACK

Implementation stack.

Python · computational geometry · half-plane intersection · minimum enclosing geometry · event-triggered logic · EvoX / PSO for parameter search · LaTeX reporting.

The main design principle is to make every move update a geometric certificate, so localization, coverage and motion planning remain coupled instead of being solved as disconnected stages.
