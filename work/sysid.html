CASE STUDY / UAV SYSTEM IDENTIFICATION

Gray-box dynamics
that stay identifiable.

Parameter estimation for a multirotor is useful only when low prediction error corresponds to physically meaningful parameters. This project focuses on preserving identifiability while fitting inertia, actuator delay and thrust/torque parameters.

PLATFORMPX4 multirotor
DATAULog flight logs
PARAMETERSJ, Tm, Kf, Kτ
FOCUSIdentifiability
01 Problem02 Pipeline03 Evidence04 Lesson
01 / PROBLEM

Prediction accuracy is not parameter credibility.

Many parameter combinations can reproduce similar trajectories over a limited excitation window. The project therefore treats excitation, parameter sensitivity and residual structure as first-class parts of the identification problem.

02 / PIPELINE

A structured gray-box workflow.

A

Signal alignment

Align commanded actuation, estimated attitude/rates and timing so actuator lag is not absorbed into unrelated parameters.

B

Motor delay

Model first-order motor response explicitly instead of letting thrust coefficients compensate for transient mismatch.

C

Physical parameters

Estimate inertia and force/torque coefficients inside physically interpretable bounds.

D

Identifiability checks

Inspect sensitivity and residual behavior so fitted parameters remain distinguishable under the available trajectory.

03 / EVIDENCE

Real-window validation.

04 / LESSON

What matters.

A lower trajectory error is not enough. The identified model should also preserve the physical meaning, sensitivity and separability of the parameters that downstream control will rely on.
